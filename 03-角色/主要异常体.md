# 主要异常体

### 1. 管理员（老周）

- **预警**：腰间钥匙串的金属碰撞声，是玩家最重要的听觉预警。
- **无影子**：任何光源下都没有影子，是对视规则的关键判断依据。
- **对视瞬移**：与他对上视线，会瞬间出现在玩家背后。
- **敲门检查**：会逐扇敲门，玩家躲门后须屏息（QTE），否则被拖出。
- **巡逻逻辑**：在楼梯间与公共区域按路线巡逻；B1 层升级为主动追逐 AI。

### 2. 各层住户怨灵

- 每层有专属异常体（3F 老师、7F 纸人、10F 饥饿宾客等）。
- 部分怨灵无害甚至提供线索（苏老师、赵守一、许文远）；部分伪装成受害者，诱骗玩家违反规则。

### 3. 影子

- 从 9F 镜像层开始跟随玩家，是贯穿后半程的持续威胁。
- **光照规则**：灯光下消失，黑暗中逐渐实体化；长时间处于黑暗会被从背后掐住。
- 与手电电量、理智值强耦合，是"资源管理 + 恐怖节奏"的复合压力源。

### 4. "母亲"（核心）

- B2 锅炉房，大楼意识具象化。
- **拟声**：模仿林音、玩家母亲及其他死者的声音，诱导玩家靠近或违反规则。
- 无法被常规手段击败，只能通过"熄灯仪式"或"摧毁核心"来解决。
