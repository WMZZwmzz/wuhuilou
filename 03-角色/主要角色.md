# 主要角色

> 本文给出四名主要角色的完整规格：设定、外观、声音、行为模式与心理弧线。异常体的对抗数值见《06-玩法机制/数值平衡表》第五节，视觉规格总则见《09-视听设计/美术风格指南》。

## 1. 林砚（玩家）

- **设定**：26 岁，程序员。父母早逝，一手把妹妹林音带大，性格理性克制、极度护短。
- **开场携带**：手机（照明+接收短信）、家门钥匙、妹妹的照片（可作为 11F 祭品）、旧双肩包。
- **外观**：深色夹克、双肩包、手机屏的冷光常映在脸上——一个"刚从加班现场走出来"的普通青年。全程不换装；随着楼层推进，夹克上的灰、水渍与划痕逐步加重，是通盘进度的隐性刻度。
- **声音**：不设配音台词（第一人称主观视点，沉默主角）；呼吸声、屏息 QTE 的心跳声是他在音频上的存在方式。仅开场/结局允许一两句低声独白。
- **行为模式**：无武器、无技能树，能做的只有走、跑、蹲、听、看、读、记（线索板自动记录）。玩家通过他的视角体验"理性者被拖入非理性"的心理弧线。
- **心理弧线**：三幕对应三个阶段——第一幕"不信邪但接受规则"（为了妹妹什么都肯做）；第二幕"怀疑一切线索"（假药、假档案让他学会交叉验证）；第三幕"目标反转"（从救妹妹到识破母亲，最终在 B2 用一整夜的积累做抉择）。

## 2. 林音（妹妹）

- **设定**：17 岁，高中生，体弱多病，拥有**通灵体质**，从小能"看见楼里的东西"。
- **处境**：七天前被"母亲"以林砚的声音/求救短信引入大楼，成为容器候选。她并非"失踪"，而是被困在大楼意识中：**肉身封存于 B2 锅炉房，意识分散在大楼各处**，所以能在各层留下日记残页、录音带与求救痕迹。她发出的短信既是本能求救，也被"母亲"借手操纵——引林砚入局。
- **外观**：从不以完整人形出现。玩家见到她的形式按进度递进：短信文字（M0）→ 日记字迹（各层残页）→ 录音带里的声音（6F）→ 大量照片/生活痕迹（13F）→ B2 中被"母亲"复制的幻象。真结局黎明时分才第一次、也是唯一一次真正现身。
- **声音**：清瘦、轻、慢，带病气。关键签名是称呼——**她只叫玩家"砚哥"**。"母亲"能模仿她的音色，却永远叫不出这个小名，这是 B2 对质与全篇辨伪的总暗号。
- **行为模式**：意识碎片表现为"帮助与警告并存"：留线索（日记、录音、门牌）、设暗号（数到十三）、也在无意间成为诱饵（被操纵的短信）。
- **弧线**：从"被拯救的对象"逐步揭示为"自救的协作者"——她在被困的七天里替哥哥完成了大半侦查，日记就是她的"通关攻略"。

## 3. 管理员 老周

- **设定**：原名**周守正**，永宁大楼 1992 年以来的夜班守楼人。2008 年火灾当晚冲入火场救人，因"回头"违反大楼规则而死，被"母亲"收编为**管理员**。其中一把钥匙是"出口钥匙"，另一把打不开任何门的旧钥匙，是当年没能打开的 1304。
- **外观**：老旧保安服、肩章褪色、腰间一大串钥匙（行动时哗啦作响）；**任何光源下都没有影子**——这是识别他与规则的视觉关键；面部永远处于"看不清"的状态，只在转头瞬间给一次模糊正脸。
- **声音**：不主动说话。钥匙串碰撞声是他的"语音"，距离越近越清晰（最强听觉预警）；B1 被夺钥匙后才开口，沙哑、缓慢、如释重负。
- **行为模式**（数值见数值平衡表第五节）：
  - 巡逻速度 1.5 m/s（慢，压迫感），追逐 4.5 m/s（略慢于玩家奔跑）——**跑得掉，但躲不掉**。
  - 对视 0.5 秒触发瞬移至玩家背后；每 60–90 秒敲门检查一次，玩家须屏息 QTE。
  - 视觉检测 120° 锥形 15 m，听觉半径 8 m（脚步与碰撞声）。
- **弧线**：回收违规者 → B1 主动追逐 → 被夺钥匙后"卸差"（S12）→ 牺牲结局中替玩家挡下致命一击。他是"管理员是可被替换的职务"这一循环隐喻的载体：替代结局里玩家接替他，暗示这个位置早已换过无数人。

## 4. "母亲"（核心）

- **设定**：位于 B2 锅炉房，是"阴地怨气 + 火灾亡者怨念"的聚合体，非女性，无固定形态。靠"进食"生者情绪维持与成长，需要容器获得实体。
- **外观**：肉壁聚合体，无数张脸在墙面隐约浮现再沉没；**不出现稳定人形**（写作红线）。只在诱导玩家时，用肉壁的隆起拼出一个"快要成为林音"的轮廓——永远差一点，差的那一点就是破绽。
- **声音**：拟声大师。可模仿林音、玩家早已离世的母亲、任何一名死者；音色可以乱真，**称呼与用词无法乱真**——只会叫"哥"，叫不出"砚哥"；只会说"过来"，说不出只有兄妹俩知道的事。
- **行为模式**：从不直接杀人。它的工作方式是"布置"：制定规则、投放假线索（假药、假出口）、操纵时空（12F/B2）、借老周与怨灵施压，把玩家熬到自愿交出悔恨。
- **拟声暗号体系**（贯穿全篇的辨伪规则）：

| 场合 | 真林音 | "母亲"的仿品 |
|------|--------|--------------|
| 称呼 | 只叫"砚哥" | 只叫"哥" |
| 诉求 | 让哥哥"别来/快走"两种矛盾并存，真实挣扎 | 一律引导"过来、靠近、开门" |
| 记忆 | 能说出兄妹私事（药、旧照片、小名） | 只会复述公开信息 |
| 声线 | 带病气、轻、慢 | 完美但"太干净"，无呼吸声 |

- **各层显现形式**：

| 楼层 | 显现/影响 |
|------|-----------|
| 1F | 监控里"站在门外的自己"（镜像诱饵的排练） |
| 4F | 假药——第一次主动投放假线索 |
| 6F | 全层门牌 1304——用林音的房间号编织迷宫 |
| 8F | 死亡日期"明天"——文书层面的宣判 |
| 9F 起 | 影子脱离本体，从"环境威胁"升级为"持续追杀" |
| 12F | 浓雾与时间加速——拖延与消耗 |
| B2 | 核心显形、拟声对质、四结局抉择 |

- **弱点**：被记住的名字与被归还的执念（详见《02-世界观设定/核心设定》第三节）。
