# 核心玩法机制

## 1. 探索与资源管理

- 收集：电池、药品、香烛、胶带、钥匙、日记残页、录音带、权限卡、遗物。
- 手电筒电量有限，黑暗中理智下降更快（**无光时 ×3**）。
- 药品可暂时恢复理智，但部分为假药，有副作用（画面扭曲、耳语加剧）。

## 2. 电梯与楼梯（双路线）

- **电梯**：快速移动，但需消耗权限卡，且可能触发随机异常（见下表）。
- **楼梯**：无权限限制，但管理员巡逻频繁，且楼梯可能**无限循环**。

**电梯随机异常事件表**

| 事件 | 表现 | 正确应对 |
|------|------|----------|
| 楼层错乱 | 按 7 层却停到 9 层 | 保持冷静，重新刷卡 |
| 13 层无端亮起 | 无人按却亮起 | 立即退出电梯 |
| 多出"乘客" | 电梯内多出一个背对者 | 不看它，等下一班 |
| 镜子异常 | 镜中自己动作不同步 | 不直视超三秒 |
| 门迟迟不开 | 停靠后门不动 | 闭眼背对门站立 |
| 无限下坠 | 电梯持续下降 | 闭眼数到七 |

## 3. 理智系统（数值化）

| 理智区间 | 表现 |
|----------|------|
| 100–75 | 正常 |
| 74–50 | 轻微幻听：弹珠声、麻将碰撞、电梯铃、墙里哭泣 |
| 49–25 | 视觉扭曲、虚假影子、妹妹声音加密集 |
| 24–1 | 出现"虚假出口"，走过去会回到原点 |
| 0 | 主动走向管理员或核心，游戏结束 |

- **恢复方式**：真药（+25）、安全区停留（缓慢）、灯光下（缓慢）、香烛（临时驱散）。
- **下降诱因**：黑暗、违反规则、异常体接触、目睹恐怖事件。

## 4. 光照与影子

- 手电、声控灯、室内灯三类光源。
- 影子在黑暗中实体化，灯光是唯一压制手段，与理智、电量形成三方制衡。

## 5. 追逐与潜行

- 管理员与部分怨灵不可击杀，只能躲避。
- 藏身点：壁橱、床底、门后（门后需屏息 QTE）。部分异常体会检查藏身点。
- 体力有限，无法长时间奔跑；追逐中需规划路线与藏身点。

## 6. 动态楼层

- 每局楼层顺序随机重排，规则真伪随机变化，谜题答案随机。
- 提升重复游玩价值，杜绝背板过关。

## 7. 谜题类型库

| 类型 | 示例 | 所在楼层 |
|------|------|----------|
| 规则推理 | 判断规则真假 | 全楼 |
| 环境谜题 | 麻将落子、拼图 | 2F、3F |
| 声音谜题 | 循录音带找真门 | 6F |
| 信息检索 | 药典、档案比对 | 4F、8F |
| 顺序谜题 | 上香顺序 | 7F |
| 空间/镜像 | 跟随延迟动作打破镜像 | 9F |
| 交易/献祭 | 献祭随身物品 | 11F |
