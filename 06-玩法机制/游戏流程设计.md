# 游戏流程设计

> 本文档将剧情主线、支线与玩法机制串接为一条**从头到尾可完整体验的流程**。所有目标、奖励与剧情衔接均与既有设定（主线 16 个、支线 13 条、四结局、理智/规则/遗物系统）严格对齐。

---

## 一、流程总览

```
启动 → 主菜单 → 开场动画(M0) → 教学关卡(M1)
  → 第一幕「踏入」(2F–4F) → 第二幕「深入」(5F–9F) → 第三幕「真相与抉择」(10F–B2)
  → 结局(四选一) → 结算/解锁 → 二周目(继承)
```

**时间轴与章节对应**：

| 阶段 | 时间 | 楼层 | 章节目标 | 通关门槛 |
|------|------|------|----------|----------|
| 开场 | 0:00 | 楼外/1F | 建立动机、学会操作 | 拾取规则① |
| 第一幕 | 0:00–1:30 | 2F–4F | 适应规则、初遇异常 | 集齐权限卡②③④ |
| 第二幕 | 1:30–4:00 | 5F–9F | 真相渐显、面对影子 | 集齐权限卡⑤–⑨ |
| 第三幕 | 4:00–6:00 | 10F–B2 | 揭示容器真相、抉择结局 | 抵达 B2 |

**通关判定（游戏结束）的四种路径**：抵达结局、理智归零、被异常体致死、6:00 未逃出。

---

## 二、开场引导（Onboarding）

开场引导的核心原则：**先恐怖钩子，后教学**，让玩家在 15 分钟内既学会操作，又被"这栋楼不对劲"抓住。

### 0. 主菜单
- 极简，仅"开始 / 继续 / 设置"。背景是永宁大楼的铁门在雾中若隐若现。

### 1. 开场动画（M0 午夜来电）
- **演出**：林砚的出租屋，凌晨 0:00。手机屏幕亮起，妹妹的短信弹出。玩家可环顾房间（照片、泡面、便签），最后拨回电话——听筒里只有电流杂音与一声似人非人的"哥"。
- **引导点**：教会玩家"环顾"与"互动"的基本操作，同时抛出核心悬念。

### 2. 教学关卡（M1 铁门之后）
- **移动/视角**：入楼后，通过狭窄的大堂走位熟悉基础操作。
- **手电与电量**：拾取手电（半格电），提示电量会耗尽、黑暗更危险。
- **蹲伏**：在倒塌的货架下教学蹲伏。
- **互动**：开门、捡拾地图、阅读《住户须知》。
- **规则系统引入**：第一张规则①贴在保安室门上，玩家第一次接触"规则真假难辨"的概念。
- **恐怖钩子**：监控屏亮起，画面里"自己"站在门外转头——教学结束的同时埋下第一颗悬念。

> **设计要点**：教学不打断叙事。所有操作提示都藏在剧情动作里（拿手电、看监控、读规则），避免"教程弹窗"破坏沉浸感。

## 三、章节/关卡推进

三幕即三章，每章由多个楼层关卡构成。**楼层的"门"由电梯权限卡（快但险）或楼梯（慢但稳）解锁**，形成关卡推进的双路线张力。

### 第一幕「踏入」（2F–4F）

| 关卡 | 目标 | 奖励 | 剧情衔接 |
|------|------|------|----------|
| 2F 麻将馆 | 解牌局 | 权限卡②、遗物S1 | 陈守财的执念，暗示"楼里全是死人" |
| 3F 幼儿园 | 躲"老师"完成拼图 | 权限卡③、遗物S2 | 苏梅的牺牲，强化"受害者"群像 |
| 4F 诊所 | 搜药 | 权限卡④、药品、遗物S3 | 真假药引入"线索不可尽信" |

- **章节 Boss**：无实体 Boss，管理员在楼梯间首次出现（钥匙声预警），建立持续压迫。
- **章节终点**：集齐权限卡②③④，电梯可直达 4F，进入第二幕。

### 第二幕「深入」（5F–9F）

| 关卡 | 目标 | 奖励 | 剧情衔接 |
|------|------|------|----------|
| 5F 网吧 | 删监控 | 权限卡⑤、遗物S4 | 阿杰的忏悔，火灾真相一角 |
| 6F 公寓 | 找录音带真门 | 权限卡⑥、录音带、遗物S5 | 妹妹的声音线索，情感升温 |
| 7F 灵堂 | 正确上香 | 权限卡⑦、香烛、遗物S6 | 赵守一"给自己上香"，生死主题 |
| 8F 档案室 | 调取档案 | 权限卡⑧、药典、出口线索、遗物S7 | **转折三**：死亡日期"明天" |
| 9F 镜像层 | 打破镜像 | 权限卡⑨、遗物S8 | **转折四**：影子登场，威胁升级 |

- **章节 Boss**：影子（从 9F 起持续跟随），光照成为生存核心。
- **章节终点**：集齐权限卡⑤–⑨，8F 的档案揭示"入楼即注定"，动机从"找妹妹"转向"求真相"。

### 第三幕「真相与抉择」（10F–B2）

| 关卡 | 目标 | 奖励 | 剧情衔接 |
|------|------|------|----------|
| 10F 宴会厅 | 找空位坐下 | 权限卡⑩、遗物S9 | 许文远的婚礼执念 |
| 11F 祭坛 | 献祭随身物 | 权限卡⑪、封印线索、遗物S10 | **转折五**：王桂枝揭示封印法 |
| 12F 天台 | 找半张全家福 | 权限卡⑫、遗物S11 | 陆家父子失散，循环机制 |
| 13F 住宅 | 读日记 | 日记遗物S13、终局线索 | **转折六**：妹妹是容器、短信是诱饵 |
| B1 停车场 | 夺出口钥匙 | 出口钥匙、遗物S12 | **转折七**：老周的旧钥匙暗线 |
| B2 锅炉房 | 最终对质 | 四结局 | **转折八**：结局抉择 |

- **章节 Boss**：管理员（B1 正面追逐战）→ "母亲"（B2 最终对峙）。
- **章节终点**：集齐权限卡⑩⑪⑫后，通过 13F 与 B1，抵达 B2，进入结局。

## 四、核心玩法循环

### 微观循环（单层内，约 10–15 分钟）

```
进入楼层 → 探索(收集线索/道具) → 解谜(规则推理/环境/声音/顺序)
  → 遭遇异常体(躲藏/遵守规则/管理理智) → 获得权限卡+遗物
  → 抉择上行方式(电梯快险 / 楼梯慢稳) → 进入下一层
```

**循环张力来源**：
- **资源压力**：手电电量、药品、香烛有限，探索越久消耗越大。
- **理智压力**：黑暗、违反规则、遭遇异常都会降理智，理智过低会"看到虚假出口"。
- **路线取舍**：电梯消耗权限卡且可能触发随机异常；楼梯无消耗但管理员巡逻 + 可能无限循环。

### 宏观循环（整局，约 4–6 小时）

```
章节推进(三幕) → 真相层层揭开 → 遗物收集(支线) → 结局抉择
```

**循环目标**：微观循环解决"如何活下去、如何往上走"，宏观循环解决"真相是什么、我该怎么办"。二者在 13F 与 B2 交汇——所有微观积累（遗物、线索、资源）最终服务于宏观的结局抉择。

---

## 五、关键剧情节点

八个转折点与玩法节点一一绑定，确保"剧情即玩法、玩法即剧情"：

| 转折 | 楼层 | 玩法触发 | 剧情内容 |
|------|------|----------|----------|
| ① 循环暗示 | 1F | 看监控屏 | "自己"在门外，暗示循环 |
| ② 线索不可信 | 4F | 发现假药 | "母亲"会误导玩家 |
| ③ 入楼即注定 | 8F | 调取档案 | 死亡日期"明天" |
| ④ 威胁升级 | 9F | 打破镜像 | 影子脱离本体 |
| ⑤ 唯一的光 | 11F | 献祭 | 王桂枝揭示封印法 |
| ⑥ 目标反转 | 13F | 读日记 | 妹妹是容器、短信是诱饵 |
| ⑦ 暗线收束 | B1 | 夺钥匙 | 老周的旧钥匙伏笔 |
| ⑧ 结局抉择 | B2 | 对质 | 四结局分岔 |

**节点衔接原则**：每个转折点都是玩家**亲手触发**的（而非过场动画强塞），且会改变玩家后续的决策依据（例如③之后，玩家会更谨慎地管理理智与资源）。

## 六、角色成长与资源获取

林砚**没有等级/技能树**，其"成长"体现在三方面：**信息积累（线索板）、道具积累、遗物收集**。

### 1. 信息成长：线索板
- 林砚随身带一本笔记本，自动记录已发现的**规则真伪、亡者遗言、真相线索**。
- 玩家可随时打开线索板复盘，它是解谜（如判断规则真假、辨别真假药）的核心辅助。
- 这是本作"成长"的主要表现——玩家和林砚一起"越来越懂这栋楼"。

### 2. 道具成长：资源节奏

| 楼层 | 关键获取 | 用途 |
|------|----------|------|
| 1F | 手电、地图、规则① | 基础生存 |
| 2F–3F | 电池×1、权限卡②③ | 补电、推进 |
| 4F | 药品(真假未明) | 理智恢复（有风险） |
| 7F | 香烛 | 驱散纸人/影子 |
| 8F | 药典、出口钥匙线索 | 辨药、定目标 |
| B1 | 出口钥匙 | 逃生关键 |

- **资源设计原则**：资源**稀缺但不苛刻**，让玩家始终"够用但不够挥霍"。电池、药品、香烛的投放节奏与理智压力同步（压力大的楼层前，会提前给一点点资源，形成"希望感"）。

### 3. 遗物成长：收集驱动
- 13 件遗物是"成长"的终极体现。每集一件，线索板会新增该亡者的故事，同时离真结局更进一步。
- 遗物**不可出售、不可丢弃、跨周目可继承**（二周目功能），是玩家"攻略进度"的实体化。

## 七、支线任务与隐藏要素

### 支线任务（13 条，S1–S13）
- 全部为**可错过、可回溯**设计。错过某层支线后，可通过电梯回溯该层补做（代价是额外消耗权限卡，见《待定与勘误》）。
- 支线回报 = **遗物**，是触发真结局的唯一途径，因此支线不是"可有可无的收集"，而是"通向圆满的必要积累"。

### 隐藏要素

| 类型 | 内容 | 触发 |
|------|------|------|
| 隐藏结局 | 真结局「熄灯仪式」 | 集齐 13 遗物 |
| 隐藏房间 | 每层一个隐藏空间（如 2F 储藏室、8F 暗格） | 满足特定条件（如不惊动异常体、按隐藏顺序操作） |
| 隐藏文本 | 亡者遗言残页、火灾当晚的未寄信件 | 散落于隐藏房间 |
| 隐藏道具 | 老周钥匙串中的"旧钥匙"（真结局关键） | M14 夺取钥匙串 |
| 彩蛋 | 1F 监控的循环暗示、6F 门后数到十三的声音 | 剧情自然触发 |

- **隐藏房间设计**：每层一个，奖励多为补充剧情文本 + 少量资源，不强制、不影响通关，但能补全世界观。

## 八、失败与重试机制

### 失败（死亡）条件

| 失败方式 | 触发 | 表现 |
|----------|------|------|
| 理智归零 | 理智降至 0 | 林砚主动走向管理员/核心 |
| 被管理员抓住 | 对视瞬移后未逃脱、敲门被拖出 | 追逐失败 |
| 被影子掐死 | 长时间处于黑暗 | 影子实体化致死 |
| 楼层即死 | 7F 纸人围拢、10F 坐错位 | 特定谜题失败 |
| 超时 | 6:00 未逃出 | 大楼消失，玩家死亡 |

### 失败惩罚与重试
- **死亡并非"读档重来"**，而是触发一段**死亡演出**（如理智归零时，林砚眼神涣散地走向黑暗），随后回到**最近安全区**。
- **安全区/存档点**：
  - 固定安全区：1F 保安室、每层电梯厅的亮灯处。
  - 自动存档：进入新楼层、完成章节关键节点时。
- **重试保留**：已收集的**遗物、关键线索、权限卡永久保留**；仅损失部分消耗品（电池、药品、香烛）。这避免挫败感，同时保留恐怖张力。
- **动态楼层提示**：因楼层随机重排，死亡后该层的谜题答案/规则真伪可能变化，玩家无法靠"背答案"硬闯——这与"动态空间"设定自洽。

## 九、多结局达成条件

### 关键变量

| 变量 | 符号 | 取值 |
|------|------|------|
| 遗物数量 | R | 0–13 |
| 是否识破拟声 | K | 是 / 否 |
| 是否取得出口钥匙 | X | 是 / 否 |
| 是否摧毁核心 | C | 是 / 否 |
| 是否举行熄灯仪式 | S | 是 / 否 |

### 判定表

| 结局 | 达成条件 | 核心分岔 |
|------|----------|----------|
| **逃离（普通）** | X=是 且 R<13 且 选择逃出 | 有钥匙、无遗物 |
| **替代（坏）** | B2 被拟声迷惑 且 选择"换回妹妹" | 未能识破（K=否更易触发） |
| **牺牲（好）** | C=是（未集齐遗物/未完成仪式） | 摧毁核心 |
| **真结局（隐藏）** | R=13 且 S=是 | 集齐遗物 + 熄灯仪式 |

### 结局触发流程（B2 锅炉房）

```
B2 对质（"母亲"拟声）
  ├─ 识破拟声(K=是) → 不被诱惑
  │     ├─ 有出口钥匙(X=是) 且 R<13 → 逃离结局
  │     ├─ 选择摧毁核心(C=是) → 牺牲结局
  │     └─ R=13 且 举行熄灯仪式(S=是) → 真结局
  └─ 未识破(K=否) → 被"换回妹妹"诱惑 → 替代结局
```

> ⚠️ **设计要点**：四结局不是线性优劣。变量系统让玩家在 B2 前"不知道自己会走向哪个结局"——是否集齐遗物、是否识破暗号，都取决于此前整局的积累。这正是"过程决定结局"的完整体验闭环。
