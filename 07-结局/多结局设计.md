# 多结局设计

> 本文负责四结局的**判定规格**（变量、条件、优先级、仪式流程、多周目）；完整演出脚本与情感落点见《04-剧情/结局演绎》，触发流程图见《06-玩法机制/游戏流程设计》第九节。三处口径一致，改其一须同步其余。

## 一、四结局速览

| 结局 | 定位 | 一句话 |
|------|------|--------|
| 逃离（普通） | 理性之痛 | 独自逃出，永远失去她 |
| 替代（坏） | 循环之怖 | 你成了新的管理员 |
| 牺牲（好） | 悲壮之爱 | 她活了下来，你留在灰烬中 |
| 真结局（隐藏） | 圆满之释然 | 十三件遗物点亮，十三个人都回家了 |

## 二、判定变量与优先级

**变量定义**

| 变量 | 符号 | 取值 |
|------|------|------|
| 遗物数量 | R | 0–13 |
| 是否识破拟声 | K | 是 / 否 |
| 是否取得出口钥匙 | X | 是 / 否 |
| 是否摧毁核心 | C | 是 / 否 |
| 是否举行熄灯仪式 | S | 是 / 否 |

**判定优先级（B2 对质界面逐级询问，先到先得）**

```
B2 对质（"母亲"拟声）
  1) R=13 且玩家选择举行仪式(S=是)        → 真结局
  2) 玩家选择"换回妹妹"（未识破时才可选）   → 替代结局
  3) 玩家选择摧毁核心(C=是)               → 牺牲结局
  4) X=是 且 选择独自逃出                  → 逃离结局
  5) 无出口钥匙且拒绝以上全部               → 追逐战开始，玩家被迫重选（不设第五结局）
```

- **K 的作用**：识破拟声（K=是）后，"换回妹妹"选项从菜单**移除**（诱惑台词照常播放，但不可选）；未识破（K=否）时该选项高亮置顶——K 不直接决定结局，而是决定玩家"有没有资格犯错"。
- **真结局门槛**：R=13 是必要非充分条件，玩家仍须在对质中主动选择仪式；集齐遗物但选逃出，仍是逃离结局。
- **逃离结局门槛**：X=是 是必要条件；未取得出口钥匙时"独自逃出"选项不存在。

## 三、熄灯仪式流程（真结局玩法化）

仪式是对质界面内的**分段交互**，每段有演出有判定，总时长约 5 分钟：

1. **布阵**：13 件遗物在锅炉房地面摆成一个圈（自动演出，镜头缓摇逐一照亮遗物）。
2. **点名**：按《03-角色/亡者遗物》总表顺序逐件交互念名（陈守财 → … → 周守正），每念一个名字，圈内亮起一点微光、亡者现身一瞬并留下回应文本（全文见《04-剧情/关键节点与文本》第七节）。念错顺序不惩罚，但全部念完才进入下一段。
3. **归还**：取出老周钥匙串中的旧钥匙，插进肉壁中央的锁孔——2008 年那晚没能打开的 1304 的门，"咔哒"开了。
4. **熄灯**：念出最后一个名字"林音"（全篇唯一只有两个字的回应："砚哥。"），然后熄灭楼内所有光源。黑暗静默三秒。
5. **黎明**：晨光落下，肉壁褪去，大楼透明、崩塌、消失；兄妹重逢，众影鞠躬消散。

**仪式失败保护**：对质界面倒计时（承接 6:00 全局时限）耗尽仍可继续仪式，但结算文案降级为"灰烬里的黎明"变体——不给第五结局，只承认差异文本。

## 四、多周目规则（已定案）

大楼每年重现，为多周目提供叙事合法性：

- **继承**：遗物图鉴（含 13 段亡者故事全文）、真相线索板、已看过的演出跳过权、结局解锁列表。
- **重置**：遗物实体（需重新收集）、消耗品、权限卡、规则真伪（重新抽取）、谜题答案与楼层顺序（空间重组设定自洽，见《02-世界观设定/核心设定》法则三）。
- **二周目新内容**：真结局后开放"名册模式"——开局即持有完整线索板，规则真伪全部直接标注，供剧情向玩家无压复游；另解锁 1F 监控的循环暗示完整版（暗合"林砚可能并非第一次入楼"的伏笔）。
- **多周目结局继承规则**：每周目独立结算四结局之一；集齐四个结局的存档解锁标题画面变化（大楼的灯，一层层亮起来）。

## 五、结算与统计

每次结局后展示：结局名与文案、游戏内用时（距 6:00）、剩余理智、遗物 n/13（含名录）、违反规则次数、死亡次数、二周目提示。统计口径与垂直切片 Demo 的结算页一致。
