# 美术风格指南

> 本作目标：**写实向的中式老旧居民楼恐怖**，贴近 90 年代城镇生活的真实质感，让恐怖"发生在熟悉的地方"。整体克制、去华丽，靠细节的"不对劲"制造恐惧。

---

## 一、整体美术风格

- **方向**：写实（PBR）+ 轻度风格化，参考《层层恐惧》的材质质感与中式恐怖片的色彩。
- **关键词**：老旧、斑驳、潮湿、昏黄、低饱和、压抑。
- **核心手法**：**"正常里藏着不正常"**——墙面剥落、水渍、发霉是"正常"；监控里多出的"自己"、遗照上是玩家本人是"不正常"。

---

## 二、色彩与光照

| 项目 | 方案 |
|------|------|
| 主色调 | 低饱和、昏黄偏冷（青灰 + 暗黄） |
| 暗部 | 不纯黑，带青绿冷调 |
| 高光 | 少、微弱，避免"干净亮白" |
| 楼层差异 | 见下表 |

| 楼层 | 色彩倾向 | 氛围 |
|------|----------|------|
| 1F 大堂 | 冷灰 + 微黄 | 陈旧、压抑 |
| 2F 麻将馆 | 暖黄（唯一偏暖） | 怀旧、却诡异 |
| 3F 幼儿园 | 褪色的粉/黄 | 童真中的恐怖 |
| 4F 诊所 | 冷白 + 消毒水感 | 无菌的阴森 |
| 5F 网吧 | 冷蓝（屏幕光） | 电子幽闭 |
| 7F 灵堂 | 红 + 白 + 黑 | 殡葬的肃杀 |
| 9F 镜像层 | 灰银 + 冷光 | 虚幻、错乱 |
| B2 锅炉房 | 暗红 + 肉色 | 血肉地狱 |

**光照**：
- 手电（暖白聚光，边缘锐利）、声控灯（昏黄、忽明忽暗）、室内灯（冷白荧光）。
- 阴影要"深且软"，制造大量视觉死角——恐怖藏在阴影里。

## 三、材质与贴图

| 元素 | 要求 |
|------|------|
| 墙面 | 剥落墙皮、水渍、霉斑、斑驳广告 |
| 地面 | 磨光的水泥、积水反光、油污 |
| 门/窗 | 锈蚀合页、模糊玻璃、铁栅栏 |
| 家具 | 蒙灰、褪色、缺失零件 |
| 纸制品 | 泛黄报纸、手写便签、规则告示 |

- **制作建议**：以 PBR 材质 + 细节贴图（dirt/grime overlay）为主，可批量复用，重点楼层（13F、B2）单独精修。
- **Demo 现状（人物）**：服装与皮鞋已改用 [Poly Haven](https://polyhaven.com/textures) 的 CC0 布料/皮革扫描
  ——棉针织、丹宁、素绉缎、棕皮革四张 1K albedo，按角色分配面料并按各自真实覆盖尺度平铺
  （授权与选型记录见 `game/textures/CREDITS.md`）。皮肤与头发**保持程序化**：可达的 CC0 站上
  没有任何人体皮肤/毛发扫描资源，仅预留 `skin_fuzz`/`hair_card`/`eye_hetero` 键位，放入同名文件即自动替换。
  外部贴图**只收 albedo，法线一律程序化**（Godot 导入的 JPG 默认按 sRGB 采样，法线需关 sRGB 才正确）。
  删除 `game/textures/` 目录后游戏仍可运行，自动回退到程序化布料。

## 四、角色与异常体美术

| 角色/异常体 | 造型要点 |
|-------------|----------|
| 管理员老周 | 破旧保安服、模糊的面部、腰间大串钥匙；**无影子**（关键视觉线索） |
| 各层怨灵 | 半透明、动作僵硬、保留生前特征（苏梅的围裙、阿杰的网管服） |
| 影子 | 无固定形态，黑暗中一团更深的黑，仅轮廓可辨 |
| "母亲" | 肉壁聚合体，无数张脸隐约浮现，无稳定人形 |

- **无影子设计**：管理员的"无影子"是判断规则的视觉关键，需在所有光源下明确表现。

**Demo 实现状态**（垂直切片，2026-08 人物建模专项后）：

| 设计要求 | 实现 |
|---|---|
| 管理员面部模糊 | ✅ `face:"blurred"`——在已画好的五官上罩一层略大于颅骨的平滑皮肤壳，轮廓与明暗在、细节糊开；`no_shadow` 保持全部件不投影 |
| 怨灵半透明 + 生前特征 | ✅ 苏梅 `alpha:0.88`，围裙/发髻/锥裙不变；阿杰为尸体（凹眼张嘴），按设定不透明 |
| 影子无固定形态 | ✅ 低理智黑影与 9F 影子壳已由 `QuadMesh` 薄片改为**体积化剪影人形**，显形时带 0.35 s 由小放大的"凝聚成形"演出 |
| 各层怨灵动作僵硬 | ✅ 3F 巡逻、B1 巡逻/追击接入程序化步态（支撑脚钉地、无滑步），摆幅刻意压低、膝铰链限位偏僵 |
| "母亲"无数张脸隐约浮现 | ✅ 肉壁巨球与浮现脸的雕刻细节因位移法线修复而真正显形（此前被光照抹平） |

⚠️ 两处未达本指南目标：**黑暗粒子凝聚**以缩放近似（无粒子系统）；**手指关节化与顶点 AO** 未做，
详见 `game/优化建议.md` 第 8.6 节。

## 六、UI 与字体

- **主体**：无 UI（沉浸式），通过环境与声音传递信息。
- **必要 UI**：主菜单、结算界面、线索板（笔记本）、道具栏（简化）。
- **风格**：极简、做旧纸张质感，中文字体用**宋体/仿宋**系，营造 90 年代档案感。
- **交互提示**：用微弱的光点/描边代替图标，避免破坏沉浸。

## 八、制作优先级建议

1. **P0（必做）**：1F、B2、13F（首尾与情感高潮）、管理员/影子/母亲造型。
2. **P1（重要）**：其余楼层、光影系统、无影子表现。
3. **P2（可选）**：高级特效（体积雾、肉壁变形）、场景叙事道具精修。
