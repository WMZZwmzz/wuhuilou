# 音效指南

> 本作以**声音驱动恐怖**为核心设计理念。钥匙声、电梯铃、弹珠落地等声音，既是氛围，也是"威胁预警"。声音设计的目标：**让玩家"听见危险"比"看见危险"更早、更频繁。**

---

## 一、设计原则

1. **声音即信息**：每个威胁都有专属预警音（管理员=钥匙声、影子=细微摩擦声、电梯异常=铃声变调）。玩家靠听觉判断距离与方位。
2. **声音即恐怖**：许多恐怖点不靠画面，靠声音（墙里哭泣、麻将碰撞、儿童唱歌）。
3. **3D 空间音频**：所有音效带方位与距离衰减，玩家可"听声辨位"。
4. **动态音频**：音效随理智值变化（理智越低，耳语越密集、失真越强）。

## 三、音乐设计

| 曲目 | 场景 | 风格 |
|------|------|------|
| 主题曲《无回楼》 | 主菜单/开场 | 低音弦乐 + 民乐点缀，压抑悠长 |
| 安全区音乐 | 1F 保安室 | 极弱、似有似无的安抚 |
| 探索氛围 | 各层 | 无旋律，持续低音垫（drone） |
| 追逐音乐 | 管理员/影子追逐 | 心跳 + 不规则打击乐 |
| 对质音乐 | B2 核心 | 合唱 + 不协和音，压迫到极致 |
| 结局音乐 | 四结局 | 分别对应：逃离=怅然、替代=诡异循环、牺牲=悲壮、真结局=释然 |

- **音乐原则**：大部分时间**无旋律**，只用低音垫维持紧张；关键节点（追逐、对质、结局）才"出声"，形成对比。

## 四、动态音频系统

| 触发 | 音频变化 |
|------|----------|
| 理智 >75 | 正常音效 |
| 理智 51–75 | 出现幻听（弹珠、麻将、电梯铃） |
| 理智 26–50 | 耳语声加密、音效轻微失真 |
| 理智 1–25 | 妹妹声音频繁、低频轰鸣 |
| 理智 0 | 一切声音拉远、变闷（走向死亡） |

- **实现**：理智值驱动一个"音频状态机"，切换混响、失真、音量与幻听音轨。

---

## 五、关键技术要点

1. **3D 空间音频**：使用 HRTF 或双耳渲染，所有预警音带方位与距离衰减。
2. **遮挡音频**：门/墙后的声音需"闷化"（低通滤波），强化"隔墙有耳"的恐怖。
3. **音量平衡**：预警音 > 氛围音 > 环境音，确保玩家能捕捉关键信息。
4. **随机化**：弹珠声、麻将声等重复音需音高/节奏随机化，避免机械感。
5. **静默的运用**：恐怖高潮前"突然安静"，是最有效的惊吓铺垫。
