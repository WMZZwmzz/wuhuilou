# 无回楼(Wuhuilou)

中式心理恐怖游戏《无回楼》的完整设计文档与 Godot 4.7 垂直切片 Demo。

一座没有出口的居民楼,15 层全流程(1F–13F + B1/B2)。玩家在理智、电量与时间的多重压力下,乘梯、解谜、对抗规则怪谈,走向不同的结局。

## 特色

- **第一人称心理恐怖**:中式都市怪谈背景,低理智触发画面扭曲、色差与暗角
- **理智值系统**:理智、电量、体力、时钟四维资源联动,违规即惩罚
- **规则怪谈式解谜**:电梯异常、楼层谜题、监控与须知交互,共六种异常事件
- **多结局**:结局由玩家全程行为结算,支持理智归零死亡与 6:00 时限死亡
- **程序化素材**:贴图、法线贴图由代码生成,音效采用外部 CC0/CC-BY 资源并支持程序化回退

## 运行 Demo

1. 安装 [Godot 4.7](https://godotengine.org/)(本机验证版本:4.7.2 stable)
2. 用 Godot 打开 `game/project.godot`,按 F5 运行
3. 追加启动参数 `-- --debug` 可呼出 QA 面板(楼层跳转、调理智/电量/时间、直通结局)

## QA

`game/qa/qa_runner.gd` 提供无头全流程断言(标题→教学→乘梯异常→全楼层谜题→结局→死亡路径),退出码 0 即全部通过;带渲染复跑时截图存至 `game/qa/shots/`。

```bash
"$GODOT" --headless --path game --script res://qa/qa_runner.gd
```
