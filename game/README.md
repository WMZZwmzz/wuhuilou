# 《无回楼》可运行 Demo(Godot 4.7)

基于本工作区《无回楼》游戏设计文档制作的第一人称 3D 中式心理恐怖游戏**可运行 Demo**:从 1F 大堂出发,经 2F–13F 逐层解谜下行,抵达 B1 停车场、B2 锅炉房,面对"母亲"核心做出最后抉择,完整体验"探索 → 规则判定 → 电梯抉择 → 理智/资源管理 → 四结局"的核心循环。

**技术**:Godot 4.7(Forward+)。贴图、法线贴图程序化生成;**音效为外部 CC0/CC-BY 资源**(`sounds/` 目录,来源与授权见 `sounds/CREDITS.md`,缺失时自动回退程序化合成);中文界面加载系统字体(微软雅黑)。渲染为 PBR 管线(粗糙度/金属度/清漆/程序化法线)+ PCF Soft 阴影 + 泛光与 ACES 色调映射;低理智时的色偏/色差/暗角由全屏后处理着色器实现。音频走 SFX/Ambience 双总线(Master 挂限幅器)。

---

## 运行方式

用 Godot 4.7 打开本目录的 `project.godot`,按 F5 运行;或命令行:

```bash
"Godot_v4.7.2-stable_win64.exe" --path game
```

调试模式加用户参数 `-- --debug`:楼层跳转、传送点位、理智/电量/时间调整、直通结局。

**电梯异常(招牌机制)**:每次乘梯 60% 触发六种异常之一(多出乘客 / 13层亮起 / 镜子延迟 / 门不开 / 无限下坠 / 楼层错乱),8 秒倒计时内按《住户须知》选择应对——正确平安(+2 理智),错误 −15 理智并附恐怖反馈;乘往 13F、B2 必触发。

**楼道规则事件**:理智 <85 时随机触发"背后有人叫你名字"——回头(−15)或数到七(+2)。

**四结局**(B2 核心对质后触发):真结局(13 遗物集齐 + 熄灯仪式)/ 牺牲结局(识破后摧毁核心)/ 替代结局(未识破被诱惑留下)/ 逃离结局(识破 + 出口钥匙独自逃出)。

## 已实现系统(对应《06-玩法机制/数值平衡表》)

- **理智 100**:黑暗 −2/s · 开手电 −0.3/s · 安全区 +0.5/s · 违规 −15 · 恐怖事件 −10~20;分档效果:幻听字幕(<75)→ 画面扭曲+虚假影子(<50)→ 虚假"出口"标志(<25)→ 理智归零 Game Over
- **手电电量**:初始 50,开灯 −1/s,电池 +50(全流程投放 6 节),归零强制熄灯
- **体力**:奔跑 −10/s,恢复 +8/s,耗尽后需回到 20 才能再跑
- **蹲伏**:Ctrl 蹲下,相机高度 1.62→0.95 缓动,速度 ×0.45;3F 躲避苏梅视野、1F/9F 等蹲下取物
- **时钟 0:00 → 6:00**:乘梯 +10 分钟(14 程 ×10=140)、解谜 +10 分钟、真实时间缓慢流动;6:00 未逃出即死亡
- **权限卡逐层链**:3F→4F→…→13F→B1(剧情解锁)→B2(夺钥匙串解锁);电梯面板按已得卡开放
- **背包**:权限卡(13 张)/ 真假药 / 电池 / 香烛 / 遗物计数(全流程可得 13/13)
- **死亡低惩罚**:Game Over 后从当前楼层重开,权限卡、遗物、谜题进度全部保留

## 自动化 QA

```bash
GODOT="/c/Users/PC/Desktop/Godot_v4.7.2-stable_win64.exe"
"$GODOT" --headless --path game --import                     # 新增/变更资源后先导入
"$GODOT" --headless --path game --script res://qa/qa_runner.gd   # 无头全流程断言,退出码 0 = 通过
"$GODOT" --path game --script res://qa/qa_runner.gd              # 带渲染复跑,截图存 qa/shots/
powershell -File qa/brightgrid.ps1 qa/shots/02-1f-lobby.png       # 截图亮度网格(非黑屏验证)
```

覆盖:标题→1F 教学(手电/须知/监控/蹲伏)→乘梯异常(正确/错误两路)→2F–12F 逐层全谜题→13F 强制异常+日记剧情→B1 追逐夺钥匙→B2 强制异常+四结局分支(真结局/牺牲/替代/逃离)→理智归零死亡→本层重试→6:00 时限死亡。

## 设计与完整版的差异

- 规则真伪在本 demo 中**恒为真**(完整版按设计每局随机);
- 走楼梯路线未实现(楼间移动统一走电梯);
- 本 demo 已覆盖设计文档的全 15 层、四结局、13 件遗物、逐层权限卡链与蹲伏机制,完整版另含联机 1v1 模式(见 `06-玩法机制/联机模式设计.md`)。
